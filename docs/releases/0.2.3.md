# rusty-alto 0.2.3

Version 0.2.3 improves the performance of sorted-language enumeration and
feature-structure evaluation, and continues the A* implementation work.

## Highlights

- Reworked sorted-language enumeration around dense, lazily initialized state
  streams, with specialized storage for common rule arities.
- Added checked sorted-language constructors and explicit validation that rule
  weights are finite probabilities in `[0, 1]`.
- Optimized feature-structure term evaluation by performing projection,
  embedding, remapping, and unification in a reusable workspace graph.
- Replaced explicit automaton result indexes with a dense compact index and
  cached probability-weight validation.
- Updated the Python `k_best` regression coverage to match the sorted-language
  ordering contract.
- Retained the lazy string A* frontier as an opt-in experiment behind the
  `experimental-lazy-astar` feature while simplifying the production A* path.
- Updated `packed-term-arena` to 0.1.3.
- Raised the minimum supported Rust version to 1.88, matching the language
  features used by the crate and the requirements of LALRPOP 0.23.

## Validation

The release is checked with all features enabled, including Rust unit tests,
binary tests, doctests, Python binding tests, and package verification.
